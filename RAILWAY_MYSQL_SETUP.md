# ⚠️ Railway MySQL Connection - Complete Setup

## समस्या: DB_HOST not set

```
⚠️  DB_HOST not set, skipping database initialization
```

यह error आता है क्योंकि Railway में MySQL service properly add नहीं है या connected नहीं है।

---

## ✅ Railway पर MySQL Setup करने के Steps

### Step 1: Railway Dashboard खोलिए
```
https://railway.app
```

### Step 2: अपने Project में जाइए
```
Dashboard → Your Project Name
```

### Step 3: MySQL Service Add करिए
```
"Add Service" button
→ Search "MySQL"
→ Click "MySQL"
→ Confirm
```

### Step 4: MySQL को App Service से Connect करिए

**Method 1: Automatic Connection**
1. MySQL service खोलिए (blue box)
2. Right side में "Connect" button दिखेगा
3. Select करिए: अपने App service को
4. Railway auto-injects variables

**Method 2: Manual Connection**
1. MySQL service में जाइए
2. "Variables" tab खोलिए
3. देखिए:
   - `MYSQL_HOST`
   - `MYSQL_PORT`
   - `MYSQL_DATABASE`
   - `MYSQL_USER`
   - `MYSQL_PASSWORD`

4. App service में जाइए
5. Variables में add करिए:
   ```
   DB_HOST=$MYSQL_HOST
   DB_PORT=$MYSQL_PORT
   DB_DATABASE=$MYSQL_DATABASE
   DB_USERNAME=$MYSQL_USER
   DB_PASSWORD=$MYSQL_PASSWORD
   ```

### Step 5: Redeploy करिए

Railway automatically redeploys जब:
- Variables change करते हैं
- GitHub पर push करते हैं

Manual redeploy के लिए:
```
Project → Deployments → Right side "..." menu → Redeploy
```

## 🔍 Check करिए MySQL Variables

Railway Dashboard में:

### App Service Variables देखिए:
```
Dashboard → Your Project → App Service → Variables
```

यहाँ ये होने चाहिए:

```
Dashboard → Your Project → MySQL Service → Variables
```

यहाँ ये होंगे:
```

MYSQL_PORT = 3306
MYSQL_DATABASE = railway
```


2. **Check करिए MySQL is running:**
   ```

   ```

3. **Check करिए Variables connected हैं:**
   ```
   MySQL Service → Variables tab
   Copy करिए सब values
   
   App Service → Variables tab  
   Manually add करिए:
   DB_HOST
   DB_PORT
   DB_DATABASE
   DB_USERNAME
   DB_PASSWORD
   ```

4. **Redeploy करिए:**
   ```
   Deployments → Redeploy
   ```

## 📝 MySQL Environment Variables Format

Railway automatically generates:

```env
# These come from MySQL service
MYSQL_HOST=mysql.railway.internal
MYSQL_PORT=3306
MYSQL_DATABASE=railway
MYSQL_USER=root
MYSQL_PASSWORD=<generated>
MYSQL_ROOT_PASSWORD=<generated>
```

Your app uses:
```env
# Map to Laravel DB config
DB_CONNECTION=mysql
DB_HOST=$MYSQL_HOST
DB_PORT=$MYSQL_PORT
DB_DATABASE=$MYSQL_DATABASE
DB_USERNAME=$MYSQL_USER
DB_PASSWORD=$MYSQL_PASSWORD
```

After everything is connected:

```

```


## 🆘 If Still Not Working

### Full Reset:

1. **Remove MySQL service:**
   ```
   MySQL Service → Settings → Delete Service
   ```

2. **Confirm App has no DB variables:**
   ```
   App Service → Variables → Remove DB_HOST, etc.
   ```

3. **Add MySQL again:**
   ```
   Add Service → MySQL
   ```

4. **Connect it:**
   ```
   MySQL Service → Connect → Select App
   ```

5. **Redeploy:**
   ```
   Deployments → Redeploy
   ```
